# Estudos

Peças de fora, dissecadas frame a frame e medidas. **Não são regra.** São insumo para
laudo: cada estudo termina separando o que confirma do que propõe mudar, e a proposta só
vira regra depois de aprovação escrita do Diretor (ver `IDENTIDADE.md`, "Como evoluir a
identidade").

| Estudo | Peça | O que rendeu |
| --- | --- | --- |
| `vox-porsche/` | *VOX-Style Animated Documentary — The History of Porsche* (MOTION LADY) | ritmo medido (12fps, 1,23s/cena, 4,3 palavras por cena), quatro mecanismos de anotação, seis propostas de método e duas de identidade |

## Material

Vídeo e frames das peças estudadas **não vêm com o plugin**: são obra de terceiros e
pesados. Os `ESTUDO.md` são autossuficientes para leitura e trazem a URL de origem de
cada peça, para baixar o material quando necessário.
