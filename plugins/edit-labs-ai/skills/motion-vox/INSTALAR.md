# Instalação (plugin `edit-labs-ai`)

Esta skill vem dentro do plugin `edit-labs-ai` — veja `corte-viral/INSTALAR.md` (é a mesma instalação). Depois do
`editlabs-setup`: `mv-novo-projeto <pasta>` monta um projeto e `mvpy <script>` roda os scripts dele.

**Higgsfield (obrigatório):** a skill gera imagens, remove fundo e gera B-roll em vídeo pelo Higgsfield. Conecte o
Higgsfield ao Claude (Configurações → Conectores). Quem ainda não tem conta cria por este link:
https://higgsfield.ai/s/claude-opus-5-5-yt-canal-labs-RygxQf
