# Fontes e base de pesquisa

As recomendações oficiais abaixo são majoritariamente voltadas a criativos e anúncios; o harness as usa como evidência de linguagem de plataforma, não como garantia do algoritmo orgânico.

## Claude Code e Agent Skills

**S1. Anthropic — Extend Claude with skills**  
https://code.claude.com/docs/en/skills  
Skill com YAML frontmatter, arquivos auxiliares, argumentos, permissões, contexto e avaliação.

**S2. Anthropic — Create custom subagents**  
https://code.claude.com/docs/en/sub-agents  
Subagentes em `.claude/agents/`, isolamento, ferramentas e memória.

**S3. Anthropic — Automate actions with hooks**  
https://code.claude.com/docs/en/hooks-guide  
Hooks para controle determinístico.

**S3A. Anthropic — Tools reference**  
https://code.claude.com/docs/en/tools-reference  
Ferramentas disponíveis no Claude Code e como declará-las no campo `tools` de um subagente.

## Uso responsável das fontes

- Diretrizes de anúncios não são equivalentes a ranking orgânico.
- Estudos de curiosidade não provam que um recurso de edição específico “gera dopamina”.
- Limites de segundos no config são hipóteses operacionais para teste, não constantes biológicas.
