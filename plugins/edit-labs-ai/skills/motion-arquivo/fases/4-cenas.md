# Fase 4 — Cenas e Diretor

**Entrega:** trípticos (INÍCIO / MEIO / FIM de cada plano, já com o acabamento) + laudo do
Diretor. 👤 portão.

```bash
python3 ferramentas/triptico.py <projeto>            # todos
python3 ferramentas/triptico.py <projeto> 3,7        # só os que mudaram
```

O Diretor responde a rubrica inteira (`referencias/rubricas-diretor.md`), por escrito, mesmo
aprovando: `veredito / achados (severidade, item, observação, correção) / próxima etapa`.
Grave em `saida/LAUDO_fase4.md`. Defeito localizado → corrige o plano, não refaz o vídeo.

O que mais reprova (em ordem): plano parado (sem câmera ou sem evento), texto que não é o
que a voz diz, asset desenhado quando existe o real, duas cores de acento no plano, texto
sobre rosto.
